# Aegis feature map

## Vault
Logins, passkeys, TOTP, secure notes, cards, bank accounts, identities, Wi-Fi, documents, software licenses, memberships, recovery codes, SSH keys, API/private keys, custom item types/fields, encrypted attachments, folders, tags, favorites, archive, trash, item history, duplicate detection.

## Generator
Passwords, passphrases, PINs, usernames, security answers, recovery codes, site presets, strength estimation, history/reuse avoidance.

## Autofill
Browser/mobile autofill, exact-domain matching, account selection, cards/identities/TOTP/passkeys, save/update detection, biometric approval for sensitive fills.

## Security Guardian
Weak/reused/old credential checks, breach signals, 2FA/passkey upgrade recommendations, phishing/domain protection, compromised-account workflow, security score.

## Privacy & device security
Zero-knowledge client encryption, encrypted metadata/search indexes/attachments, per-vault/item/device keys, authenticated encryption, Argon2id target KDF, key rotation, integrity protection, minimal metadata, opt-in telemetry, local-first operation, biometrics, platform keystores, FIDO2/WebAuthn/security keys, auto-lock, lock on sleep/reboot/inactivity, item unlock, clipboard clearing, screenshot/app-switcher privacy, panic lock, Lock Everywhere, Privacy Mode, Travel Mode.

## Sharing & recovery
E2EE sharing, expiry/view limits/revocation, family vaults, granular permissions, emergency access, recovery kit, trusted recovery, digital inheritance, encrypted backup/restore.

## Identity & developer
Private personas/aliases, identity/payment autofill, digital-footprint cleanup, SSH/API/env secrets, certificates, secret rotation reminders.

## Platforms
Web/PWA, Android, iOS/iPadOS, Windows/macOS/Linux desktop, Chrome/Edge/Firefox/Safari extensions, CLI. One compatible encrypted vault format and sync protocol.
